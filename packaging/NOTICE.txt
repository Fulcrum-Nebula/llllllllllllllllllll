20l TyPeX Demo 0.1.0 — experimental, unsigned Windows plugin
Windows runtime gates A10–A17: NOT RUN. Do not disable SmartScreen/security.

Official PIME 1.3.0-stable is a separately installed prerequisite:
https://github.com/EasyIME/PIME/releases/tag/v1.3.0-stable
It is not bundled, owned, updated or uninstalled by this plugin. PIME/libIME2
have LGPL and other third-party license obligations; consult the official
release/source notices. No native PIME source code or binaries are copied
into this plugin. Windows API declarations are provided by windows-rs.

Only Windows 11 x64 local desktop, with an interactive administrator using
same-user UAC consent, is supported by this installer. Over-the-shoulder
credentials, standard-user installation through a different administrator,
remote desktop and service sessions are refused. Profile GUID is fixed.
Other users' profiles are not touched. Sign out/back in to reload PIME;
no process is killed. Submit/cancel before switching fields/profiles.

TyPeX may lose drafts or leave raw preedit text in the application on forced
termination. Native focus, non-BMP cursor, sensitive controls, latency and
host logging require Windows validation. The backend has no input telemetry;
this does NOT establish that the official host does not log input.
